# Advent of Claude Code Solutions

This repo tracks the solutions that claude code generated for each of the advent of code problems.
Solutions are produced by the solver in this repo: https://github.com/pachuc/advent-of-claude-code
This repo essentially tracks the workspace/ directory that the agent uses when solving the problems.
Committing this seperately as these are solutions produced by 1 run of the agent, and basically just the output of the other repo.
It is fun still to keep these solutions around to understand the trajectory the agents took in solving the problem.
