## Implementation Approach

### Position Calculation
The key insight is that the grid is filled diagonally:
- Diagonal d contains d elements
- For position (row, col), it's on diagonal d = row + col - 1
- The position within that diagonal is col
- Total position = (d-1) * d / 2 + col

For our input (2978, 3083):
- Diagonal: 6060
- Position: 18,361,853

### Code Generation
Starting from code 20151125, each subsequent code is generated by:
1. Multiplying the previous code by 252533
2. Taking the remainder when divided by 33554393

This iterative approach generates ~18.36 million codes to reach our target position.
