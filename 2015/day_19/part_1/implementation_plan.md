# Implementation Plan: Molecular Replacement Calibration

## Overview
Create a Python script to calculate the number of distinct molecules that can be generated by performing exactly one replacement on a medicine molecule using a set of replacement rules.

## Algorithm Analysis

### Problem Characteristics
- Input size: ~45 replacement rules, medicine molecule ~500-600 characters
- Operation: String pattern matching and replacement
- Output: Count of distinct molecules

### Complexity Considerations
- Time Complexity: O(R × M × L) where:
  - R = number of replacement rules (~45)
  - M = length of medicine molecule (~500-600)
  - L = average length of replacement strings (~5-10)
- Space Complexity: O(D × L) where D is number of distinct molecules (likely hundreds to thousands)
- A set-based approach for tracking distinct molecules is optimal

### Chosen Approach
1. **Parse input** to separate rules from the medicine molecule
2. **For each rule**, find all occurrence positions of the source pattern in the molecule
3. **For each occurrence**, generate a new molecule by replacing that specific occurrence
4. **Use a set** to automatically handle uniqueness
5. **Return the size** of the set

This approach is efficient for the given input size and avoids redundant computations.

## Implementation Steps

### Step 1: Input Parsing
**Objective**: Read and parse the input file to extract replacement rules and the medicine molecule.

**Details**:
- Read all lines from the input file
- Dynamically identify the blank line separator (don't hard-code line numbers)
- Parse all lines before the blank line as replacement rules:
  - Split each line by " => " to get source and replacement
  - Store as list of tuples: `[(source, replacement), ...]`
- Extract the line after the blank line as the medicine molecule string (strip whitespace)
- Handle potential edge cases: skip empty lines at start, ensure blank line exists

**Parsing Algorithm**:
```python
lines = [line.strip() for line in file.readlines()]
blank_index = lines.index('')  # Find the blank line
rules = [parse_rule(line) for line in lines[:blank_index] if line]
medicine = lines[blank_index + 1]
```

**Data Structures**:
```python
rules = []  # List of tuples: [(source, replacement), ...]
medicine = ""  # String: the starting molecule
```

### Step 2: Find All Pattern Occurrences
**Objective**: For a given source pattern, find all starting positions where it occurs in the medicine molecule.

**Details**:
- Implement a function `find_all_occurrences(text, pattern)` that returns a list of indices
- Use a sliding window approach to check each position in the text
- Must find ALL occurrences including overlapping ones (e.g., "HH" in "HHH" at positions [0, 1])
- Note: Could use `str.find()` iteratively with start position, but the simple sliding window is clearer

**Implementation approach**:
```python
def find_all_occurrences(text, pattern):
    positions = []
    for i in range(len(text) - len(pattern) + 1):
        if text[i:i+len(pattern)] == pattern:
            positions.append(i)
    return positions
```

**Alternative using str.find()** (optional, if preferred):
```python
def find_all_occurrences(text, pattern):
    positions = []
    start = 0
    while True:
        pos = text.find(pattern, start)
        if pos == -1:
            break
        positions.append(pos)
        start = pos + 1  # Move by 1 to catch overlaps
    return positions
```

**Complexity**: O(M × P) where M is text length, P is pattern length

### Step 3: Generate Molecules from Single Replacement
**Objective**: For each rule and each occurrence of its source pattern, generate a new molecule.

**Details**:
- Iterate through all replacement rules
- For each rule (source, replacement):
  - Find all occurrences of `source` in the medicine molecule
  - For each occurrence position:
    - Create a new molecule by replacing only that specific occurrence
    - String slicing: `molecule[:pos] + replacement + molecule[pos+len(source):]`
    - Add the new molecule to a set of distinct molecules

**Data Structure**:
```python
distinct_molecules = set()  # Set of strings
```

**Why a set**: Automatically handles duplicates - if the same molecule is generated through different replacements, it's only stored once.

### Step 4: Main Processing Logic
**Objective**: Orchestrate the entire process.

**Details**:
The main logic will be implemented inline in the `solve()` function rather than creating a separate `generate_molecules()` function. This keeps the code straightforward and easy to understand for a script-based solution.

```python
def solve(input_file):
    # Step 1: Parse input
    rules, medicine = parse_input(input_file)

    # Step 3: Generate all possible molecules
    distinct_molecules = set()

    for source, replacement in rules:
        # Step 2: Find all occurrences
        positions = find_all_occurrences(medicine, source)

        # Generate new molecule for each position
        for pos in positions:
            new_molecule = (
                medicine[:pos] +
                replacement +
                medicine[pos+len(source):]
            )
            distinct_molecules.add(new_molecule)

    # Return count
    return len(distinct_molecules)
```

### Step 5: Output the Result
**Objective**: Display the final count.

**Details**:
- Print the count of distinct molecules
- Format: Simple integer output

## Code Structure

```python
def parse_input(filename):
    """
    Parse input file to extract replacement rules and medicine molecule.

    Returns:
        tuple: (rules, medicine) where rules is list of (source, replacement) tuples
    """
    with open(filename, 'r') as f:
        lines = [line.strip() for line in f.readlines()]

    # Find blank line separator dynamically
    blank_index = lines.index('')

    # Parse rules (all lines before blank line)
    rules = []
    for line in lines[:blank_index]:
        if line:  # Skip any empty lines
            source, replacement = line.split(' => ')
            rules.append((source, replacement))

    # Get medicine molecule (line after blank)
    medicine = lines[blank_index + 1]

    return rules, medicine

def find_all_occurrences(text, pattern):
    """
    Find all starting positions where pattern occurs in text (including overlaps).

    Args:
        text: String to search in
        pattern: String pattern to find

    Returns:
        list: List of starting indices where pattern occurs
    """
    positions = []
    for i in range(len(text) - len(pattern) + 1):
        if text[i:i+len(pattern)] == pattern:
            positions.append(i)
    return positions

def solve(input_file):
    """
    Main solution function. Counts distinct molecules from single replacements.

    Args:
        input_file: Path to input file

    Returns:
        int: Count of distinct molecules
    """
    # Parse input
    rules, medicine = parse_input(input_file)

    # Generate all possible molecules
    distinct_molecules = set()

    for source, replacement in rules:
        # Find all occurrences of source pattern
        positions = find_all_occurrences(medicine, source)

        # Generate new molecule for each position
        for pos in positions:
            new_molecule = (
                medicine[:pos] +
                replacement +
                medicine[pos+len(source):]
            )
            distinct_molecules.add(new_molecule)

    return len(distinct_molecules)

if __name__ == "__main__":
    result = solve("input.md")
    print(result)
```

## Edge Cases to Handle

1. **Overlapping patterns**: Pattern "HH" in "HHH" should find positions [0, 1]
2. **Multiple rules for same source**: Multiple rules like "H => HO" and "H => OH" should all be applied
3. **Single character patterns**: Patterns like "H", "O" should work correctly
4. **Long replacement strings**: Some replacements like "CRnFYFYFAr" are quite long
5. **Duplicate molecules**: Same molecule generated different ways should count as one
